# Orbit 
Orbit is a map of "third places", defined as social environments away from home and work. Orbit aims to help its users dicvoer, share, and provide their thoughts on third places local and abroad. This app uses a map-based interface and leverages community engagement to provide its users with a meaningful way of finding and connecting with others in the comfort of their own third place. 


## Getting Started 
### Prerequisites
* Node.js
* npm

### Installation 
Open your terminal and navigate to where you would like to install this program. Follow the directions below. 
```
git clone https://github.com/rhmcgough/orbit.git
cd orbit
npm install
```

### Running Locally 
```
npm run dev
```
